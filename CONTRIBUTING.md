# Участие в разработке

Спасибо за интерес к проекту. Перед pull request опишите прикладную проблему, не добавляйте несвязанные изменения и выполните локальные проверки:

~~~bash
npm ci
npm test
npm run check
~~~

Не добавляйте реальные персональные данные, токены или закрытые рабочие материалы в тестовые записи.
