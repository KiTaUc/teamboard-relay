# Интерактивная проверка Teamboard Relay

В локальном браузерном запуске проверено отображение полей локального участника, роли, модераторского контекста, задачи, назначения и метаданных передачи файла. В поле участника введено имя «Мира» для создания тестовой роли модератора. Следующий шаг — создать участника и проверить настоящее переназначение существующей задачи.

Роль «модератор» выбрана и учётная запись «Мира» создана. После сохранения она появилась и в контексте модератора, и в списке получателей задачи.

Добавлен второй участник «Илья» с ролью исполнителя. Список получателей теперь содержит и модератора, и исполнителя, что позволяет проверить перенос задачи между разными участниками.

Создана задача «Проверить сборку», первоначально назначенная на «Мира · модератор», с метаданными передачи `release-checklist.md`. Для неё появились действия «Принять», «Переназначить» и «Архивировать».

Модератор «Мира» переназначил задачу на «Илья · исполнитель». Задача сохранилась в доске с прежними метаданными передачи, статусом «переназначено» и записью в истории о действии модератора.
